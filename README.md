# 📝 HTML Forms

A simple **HTML Forms** project created to practice different types of HTML form elements and inputs.

## ✨ Features

* 📝 Text input fields
* 📧 Email input
* 🔒 Password input
* ☎️ Phone number input
* 🔘 Radio buttons
* ☑️ Checkboxes
* 📋 Dropdown/select options
* 🔘 Submit button
* 🎨 Basic CSS styling

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 Live Website

https://zaidy7433.github.io/html-forms/

## 🎯 Purpose

This project was created to practice **HTML forms, input types, buttons, labels, checkboxes, radio buttons, and select options**.
